# skills

Agent skills for software development.

## Install

```bash
npx skills@latest add alexhemmingsen/skills
```

To update, run `npx skills@latest update`. To pick up new skills, re-run `add`.

## Skills

| Skill | What it does |
| --- | --- |
| `inspect-component` | A drawer of controls beside a component on the page you already have open. Change what the component shows through its props, adjust the design in context, then implement it and remove the drawer. Invoke with `/inspect-component <component>`. |
| `illustrate` | Build an illustration or motion graphic for a brand site, presentation, dashboard or anything else. The agent first asks what a good first attempt needs: the idea, style references, a video or site for the motion, where it lives, assets and requirements. Invoke with `/illustrate <subject>`. |

## Related libraries
