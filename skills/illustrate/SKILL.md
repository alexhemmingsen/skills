# Illustrate

Invoked with a subject ("an illustration for the pricing page"), start with question 1. Invoked bare, start with question 1 too.

An illustration built without answers goes off on a tangent, and the user does not know what an agent needs to hear. So ask each question below, **one at a time**: send one, wait for the answer, then send the next. Skip any the user has already answered, and accept "skip" for any of them.

## How to ask

- **One thing per question.** Never fold two questions into one, and never add a second question as a "it also helps to know". Each question below is its own message.
- **Ask plainly.** These answers are what the first attempt is built from, so ask as the important thing it is. Use the question as written, with no added hedges or extras ("it also helps to know…").
- **Use this format**, with the question number counting up from 1:

```
❓ 1: <the question>

Tip: <what will get the best result>
```

## The questions

1. **What should the illustration show?**
   Tip: Be specific. "A person baking a cake" works; "something cool" gives nothing to work from. When the answer is vague, ask question 1 again with a sharper tip, until it is specific. The idea is critical to understand.
2. **Do you have any concept in mind already? If so, explain it here.**
   Tip: Describe it in your own words: a scene, a metaphor, a composition, or a link to something close to it. A concept you already have saves the most rounds.
3. **Which reference screenshots should the style come from?**
   Tip: Two or three screenshots of illustrations whose style you want. The clearer the style is in them, the closer the first attempt will be.
4. **Which video or website shows the look, feel and motion you want?**
   Tip: A live website is best, because its exact timings can be read from its code. A short screen recording works too: 3 to 5 seconds, zoomed in on what to watch.
   When the user wants to share a video, check whether ffmpeg is installed (`which ffmpeg`). When it is not, propose installing it, and install only after they agree.
5. **Where on the page does the illustration go?**
   Tip: Say what sits above and below it, for example "below the headline, above the signup button".
6. **Do you have any assets you prefer the illustration uses?**
   Tip: SVGs, product screenshots or UI, logos, icons. Attach them or give their file paths. Real assets look better than objects drawn from shapes.
7. **Do you have any colors you prefer the illustration uses?**
   Tip: Give hex values or name the brand colors.
8. **Do you have any fonts you prefer the illustration uses?**
   Tip: Name the fonts, or say "the site's fonts". Skip this when the illustration has no text.
9. **Do you have any text sizes you prefer the illustration uses?**
   Tip: Give sizes, or say "match the site". Skip this when the illustration has no text.

## Then

When the questions are answered, or the user has said to skip some, make the first attempt from the answers.
