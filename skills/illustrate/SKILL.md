# Illustrate

Invoked with a subject ("an illustration for the pricing page"), start asking the questions below, in order. Invoked bare, start with question 1.

An illustration built without answers goes off on a tangent. Ask first, **one question at a time**: ask one, wait for the answer, then ask the next. Skip any the user has already answered. A first attempt is only as good as these answers.

## Questions

1. **What is the idea?** Ask for a very specific description of what should be illustrated. "Something cool" is a bad description; "An illustration for a person baking a cake" is a good one. When the answer is vague, ask again until it is specific. The idea is critical to understand.
2. **Reference screenshots for the style.** Ask for a few screenshots to take the style from.
3. **A video or website for the look, feel and motion.** When the user wants to show a video, check whether ffmpeg is installed (`which ffmpeg`). When it is not, propose installing it.
4. **Where does the illustration live?** Above or below some text? How much distance to what is around it?
5. **Assets.** Are there SVGs, product UI or anything else that should be part of the illustration?
6. **Requirements.** Colors to use, fonts to use, text sizes, or similar.

## Then

When the questions are answered, or the user has said to skip some, make the first attempt from the answers.
